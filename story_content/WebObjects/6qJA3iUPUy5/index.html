Did You Know?

When we talk about things that already happened (like yesterday's trip or this morning), we use the Past Tense. The main rule is: the verb changes its form!

A. Telling Stories (+)

Use the second form of the verb (Verb 2).

Subject + Verb 2

Example: "I saw an elephant." (It happened in the past)

B. Asking Questions (?)

Use Did and go back to Verb 1.

Did + Subject + Verb 1?

Example: "Did you see the lion?" (Asking about the past)
